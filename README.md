EMBERFALL — a pure 2D canvas arcade game with no external libraries, all code and art procedural. Catch falling embers (+score, +fire fuel), dodge ice shards (fire −18, life −1); power-ups: golden embers x3, ice shield (S), slow time (T). The fire meter drains constantly; fire out or 3 lives lost = game over. Levels rise every 30 seconds, combo multiplier up to x5, procedural WebAudio sound. Controls: arrow keys / WASD + mouse.

## Run it

```sh
python3 -m http.server 8000 --directory game
# open http://localhost:8000
```
